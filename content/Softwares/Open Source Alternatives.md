### 💻 Commercial Software & Their Open-Source Alternatives

* **Microsoft 365 (Word, Excel, PowerPoint)**
  * *Open-Source Alternative:* **[LibreOffice](https://www.libreoffice.org/)** — Powerful, feature-rich open-source office suite supporting document creation, spreadsheets, and presentations.

* **Adobe Photoshop**
  * *Open-Source Alternative:* **[GIMP](https://www.gimp.org/)** (GNU Image Manipulation Program) — The premier open-source raster graphics editor for image retouching, composition, and authoring.

* **ArcGIS Pro**
  * *Open-Source Alternative:* **[QGIS](https://qgis.org/)** — Free and open-source geographic information system (GIS) providing spatial data analysis, cartography, and editing.

* **Microsoft OneNote**  *
  * *Open-Source Alternative:* **[Obsidian](https://obsidian.md/)** — A powerful, extensible knowledge base that works on local Markdown files (free for personal use with a proprietary core).

* **Microsoft Notepad**
  * *Open-Source Alternative:* **[Notepad++](https://notepad-plus-plus.org/)** — Free, fast, and lightweight source code editor and text replacement utility for Windows.

* **Microsoft SQL Server **
  * *Open-Source Alternative:* **[SQLite](https://www.sqlite.org/)** — Public domain, self-contained, serverless, high-reliability SQL database engine.

* **File synchronisation**
  * *Open-Source Alternative:* **[FreeFileSync](https://freefilesync.org/)** — Open-source folder comparison and synchronization software designed to backup and manage large datasets.

* **Windows Media Player**
  * *Open-Source Alternative:* **[VLC Media Player](https://www.videolan.org/vlc/)** — Cross-platform open-source media player and framework capable of playing almost all multimedia files, discs, and streams.

* **Adobe Digital Editions **
  * *Open-Source Alternative:* **[Calibre](https://calibre-ebook.com/)** — Free and open-source e-library management suite supporting library organization, conversion, and reading.
  * *Open-Source Alternative:* **[Thorium Reader](https://www.thorium.edrlab.org/)** — Fast, highly accessible open-source EPUB and PDF reader designed for desktop platforms.

* **Microsoft Snipping tool **
  * *Open-Source Alternative:* **[Greenshot](https://getgreenshot.org/)**— Lightweight, open-source screenshot software tool optimized for quick captures and annotations.

* **Software version control**
  * *Open-Source Alternative:* **[Git](https://git-scm.com/)** — The foundational open-source distributed version control system for tracking changes in source code.
