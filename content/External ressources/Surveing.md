## 📷 Photogrammetry & Reconstruction

* **[AliceVision](https://alicevision.org/)** — Photogrammetric Computer Vision Framework providing advanced 3D reconstruction and camera tracking algorithms.

* **[Meshroom](https://alicevision.org/#meshroom)** — Free, open-source 3D Photogrammetry software based on the AliceVision framework, offering a node-based workflow for turning photographs into 3D models.

---

## 🧊 Mesh & Point Cloud Processing

* **[MeshLab](https://www.meshlab.net/)** — Open-source system for the processing and editing of unstructured 3D triangular meshes and point clouds, ideal for cleaning up noise, hole-filling, and repairing scan data.

* **[CloudCompare](https://www.cloudcompare.org/)** — 3D point cloud and mesh processing software designed for comparing 3D models, point cloud alignment, spatial analysis, and handling massive point cloud datasets.
